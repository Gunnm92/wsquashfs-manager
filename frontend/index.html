        Diagnostic du lanceur

        —

        Serveur

        Lecture seule : fixé au démarrage par les variables WSQUASHFS_MGR_* (voir le README).

        Compresser dossier(s)

        Chaque proposition est justifiée et modifiable ; rien n'est écrit dans les dossiers (l'autorun choisi est injecté dans l'image). Les dossiers décochés sont ignorés.

        Installer sur…

        Le jeu est copié dans ce dossier ; ajoute-le ensuite toi-même à Steam ou à ton lanceur. Un envoi coupé reprend où il s'est arrêté.

        Désinstaller de…

        L'image est supprimée du client (pas d'archive : elle reste dans la bibliothèque). Le jeu ne doit pas être lancé.

        Associer un client

        Sur le client : wsquashfs-launcher --pair, colle ici le code affiché (il ne sert qu'une fois, pendant que --pair attend) ; puis wsquashfs-launcher --agent pour qu'il reste joignable.

        Dossiers synchronisés

        Dossiers synchronisés comme des jeux (par exemple les sauvegardes d'un autre émulateur). Il suffit de le déclarer sur un client : il se propage ensuite comme une sauvegarde (un client qui le reçoit le déclare au même chemin, à partir de son dossier personnel). Retirer une déclaration ne supprime aucun fichier.

        Supprimer des sauvegardes

        Sur chaque client, la sauvegarde est archivée dans le dossier des backups avant d'être effacée ; sur le manager, elle reste dans ses versions précédentes. Le jeu doit être arrêté.

        Départager

        Les deux versions sont gardées sur le manager : celle que tu ne choisis pas reste archivée.

        Restaurer

        La version choisie redevient la copie du manager ; l'actuelle est archivée, tu peux y revenir. Un client qui a joué depuis sa dernière synchro passe en conflit au lieu d'être écrasé.

        Connexion

        L'application réécrit les images : un mot de passe est requis.

        Diagnostic du lanceur

        wsquashfs-launcher --doctor sur le client d'essai

        Maintenance du lanceur

        Actions immédiates : elles ne passent pas par « Enregistrer ».

        Lister les jeuxJeux montés ou en cours.
        Démonter les jeuxUn jeu en cours est arrêté.
        NettoyerCopies de travail, doublons de sauvegardes, anciennes archives. Ce que les jeux ont écrit est gardé.
        Copier les sauvegardesDe tous les jeux vers saves/<système>/<jeu> dans la ludothèque. Rien n'est supprimé.
        Synchroniser les sauvegardesAvec les autres clients associés du réseau local : la plus lourde gagne (à taille égale, la plus récente), l'autre est archivée. Association une fois, en ligne de commande : wsquashfs-launcher --pair sur l'autre client, puis wsquashfs-launcher --sync wsq://… sur celle-ci.
        État de la synchroCe qui serait synchronisé, sans rien changer.
